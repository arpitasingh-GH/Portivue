PORTIVUE — STUDENT PORTFOLIO PROTOTYPE
=====================================

Portivue is a React, TypeScript, and Vite student portfolio app. Its optional
Google Gemma 4 assistant uses a locally running Ollama server. The model is not
bundled with the app.

USE REAL GEMMA 4
---------------
1. Install Ollama from https://ollama.com/download
2. Open PowerShell and download Gemma 4 E2B:
       ollama pull gemma4:e2b
   Ollama normally starts its local API automatically. If needed, run:
       ollama serve
3. In the Portivue folder, run:
       npm install
       npm run dev
4. Open the local URL shown by Vite.
5. Open the assistant settings and select:
       Model: Gemma 4 E2B
       Ollama endpoint: http://localhost:11434/v1
6. Send a prompt. Successful answers show the model source. Connection or
   model errors are reported rather than silently replaced with demo answers.

You can also configure Vite by copying .env.example to .env and setting:
       VITE_GEMMA_ENDPOINT_URL=http://localhost:11434/v1
       VITE_GEMMA_MODEL=gemma4:e2b
Restart npm run dev after changing .env. Saved assistant settings in the
browser take precedence; if you previously used Portivue, set the endpoint
in the settings panel.

The model selector also offers gemma4:e4b, gemma4:12b, gemma4:26b, and
gemma4:31b. Larger models need more storage and hardware resources.

OFFLINE DEMO MODE
-----------------
Without a configured endpoint, chat uses fixed examples labeled
"Offline demo — not AI." These are not generated by Gemma. AI-powered bio
and entry polishing requires a working Ollama endpoint.

IMPORTANT PROTOTYPE NOTES
-------------------------
- Accounts and portfolio data are stored in this browser. The Supabase
  migration files do not connect this prototype to a production backend.
- A custom endpoint's optional API key is stored in browser local storage.
  Do not enter production credentials in this client-side prototype.
- Sample certificate links are course information, not proof of a credential.
